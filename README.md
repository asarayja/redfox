# Redfox sin verden

Nettsiden til Redfox, den røde reven: https://asarayja.github.io/redfox/

## Hva ligger hvor

| Fil / mappe | Hva |
| --- | --- |
| `index.html`, `assets/` | Selve siden |
| `data/site.json` | Alt innholdet: tekster, album, sanger og bilder |
| `Redfox/` | Lydfilene til albumene |
| `musikk/<album-id>/` | Nyere lydfiler, én mappe per album |
| `bilder/` | Bilder. `deling.jpg` vises når siden deles |
